② 复制哪段提示词

下面这段就是你给我的原版 Drift calm 设计提示词（零改动）。它是"零依赖单文件"——所有 CSS 内联、不依赖任何外部 CDN，用真实照片/视频即可。别人粘到 WorkBuddy 就能出同款。注意：首屏最好用一段真人慢动效视频，若不方便就用自己的证件照（我会用 ken-burns 慢推代替）。
请帮我做一个「Drift calm 风」的单文件落地页：一个 .html 文件，双击就能在浏览器打开，所有 CSS 内联、不依赖任何外部 CDN。完整保留 Drift 的所有排版、动效与交互（汉堡变 X 动画、卡片从右滑入、左栏 sticky、滚动高亮导航），只替换文字和素材，不要删任何效果。

【搭建规格——照做，不要改】
首屏：满屏高度，背景是动态视频（素材①），上铺半透明黑色遮罩；顶部居中一个白色圆角胶囊导航，左边写我的名字 + "."，右边一个汉堡按钮（点击两道线动画变成 X）；底部居中大标题两行（第一行常规无衬线大字，第二行里指定的那个词用衬线斜体），下方一句副标题，再下方一个半透明毛玻璃条 + 一个白色「免费报名」按钮。

关于区：奶油色背景(#F6E4CF)、顶部圆角 25px 上叠盖住首屏；居中一段介绍文字；两个胶囊按钮（深色「联系我的名字」带邮件图标 / 浅色「关注动态」带加号图标）；一条装饰分隔线（小圆点+横线+小圆点）；底部左侧 LOGO 文字「Calm / Amplified」，右侧一大段介绍（配素材②照片）。

特性区：深色背景（用素材②照片做模糊暗化处理当背景图），左栏 sticky 显示总标题 + 三个特性导航按钮（点击平滑滚动到对应卡片），右栏三张玻璃卡片从右侧滑入、滚动时高亮对应导航；每张卡有 LOGO、标题、一张 16:9 图片（素材③）、一段描述。

【素材处理】
① 我的证件照 → 请先用这张照片生成一段 5 秒 1080P 慢动效视频（微笑加深 + 轻微呼吸感 + 极轻微头部摆动），作为首屏背景视频；不便生视频就用这张照片本身做 ken-burns 慢推效果代替。
② 关于区照片与特性区背景都用同一张证件照。
③ 三张特性卡图片：未拖图就为每张生成一张适配深色背景的 16:9 横版配图（不要水印）。

【我的个人信息】（自动拆分到标题 / 副标题 / 按钮 / 三张特性卡里）：
我是小沅老师，AI 讲师、心理咨询师、高级人工智能训练师。我做的工具顺着你的节奏走，而不是压过它——为轻松、专注与心流而设计。我的三门主打内容是：AI 零代码编程（不懂代码也能做开发，用自然语言搭网站和 APP）、Vibe Coding（从一句话想法出发，AI 帮你把灵感变成作品）、AI × 心理学（用心理咨询视角设计学习节奏，帮你留在当下不内耗）。

不要向我提问，直接生成网站文件，所有素材与 HTML 放在同一文件夹、用相对路径引用，我双击 HTML 就能看到完整效果。

③ 别人操作的 SOP（手把手 7 步）

  1. 打开 WorkBuddy，新建一个对话。
  2. 复制上面整段提示词（从"请帮我做一个"到"看到完整效果"）。
  3. 把【我的个人信息】换成你自己的真实资料（名字、定位、三门主打内容）。
  4. 把你的证件照拖进对话框一起发（做首屏视频/照片用）。
  5. 发送，等它生成 index.html + 素材文件夹（单文件，几秒到一分钟）。
  6. 双击本地 index.html 预览——所有 CSS 内联、零外部依赖，离线也能开。
  7. 部署：用 WorkBuddy 的「发布 / 部署」功能，拿到一个谁都能点开的链接，发到群里。
关键提醒：这段提示词是"零依赖单文件"，比 React 那几款更稳——没有任何外部 CDN，别人双击就能看。它是"款式模板"，别人填自己信息出的是他自己同款站。三张特性卡图若没拖图，WorkBuddy 会自动生成适配深色背景的配图。
