③ 路线 A 提示词（中文模板 · 复制这段）

复制下面整段，粘到 WorkBuddy 对话框，把【方括号】换成你自己的信息即可。

请帮我做一个单文件 HTML 个人网站（CSS/JS 全内联，手机适配，双击即可打开），风格对标 Viktor Oddy / Vortex Studio 那种「暗色高级、大留白、滚动叙事」的作品集风：

【视觉】
- 主色 深墨 #051A24，次墨 #0D212C，正文 #051A24，弱文 #273C46；背景纯白 #fff。
- 字体：英文/数字用 PP Neue Montreal（没有就回落 system-ui）；大标题衬线用 PP Mondwest（没有就回落 Fraunces / Georgia）。
- 大量留白，章节之间用间距分隔，不用粗分割线；圆角大（rounded-40px），阴影用多层柔影。

【结构（从上到下）】
1. Hero：姓名（衬线大字）+ 一行身份（mono 小字）+ 一句主张 + 三段介绍 + 两个圆角按钮（主按钮深墨底白字 / 次按钮白底描边）。
2. 无限跑马灯：一行横向无限滚动的图片带（用我自己的真实照片/作品图）。
3. 引言区：一句衬线大字主张 + 署名 + 一张视差图（滚动时轻微上下位移）。
4. 双定价卡：深墨底一张 + 白底一张，圆角 40px，含标题/一句话/价格/按钮。
5. 学员好评轮播：横滑卡片，每张一张真实好评截图 + 一行"学员真实好评"标注，自动轮播 + 左右箭头。
6. 项目墙：3 个竖向项目，每个左侧标题+一句话，下面一张大图（真实成果图）。
7. 合作区：大留白圆角区块，衬线大字"与我们合作" + 一个深墨圆角按钮；鼠标移动时在光标处冒出小图（用真实图）。
8. 页脚 + 版权行（城市）。
9. 底部悬浮导航：固定底部居中圆角胶囊，含一个衬线 logo 字 + 一个主按钮。

【动效】
- IntersectionObserver 滚动揭示（translateY 30px→0 + 透明度），触发一次。
- 跑马灯 CSS 无限滚动（marquee）。
- 视差图随滚动位移。
- 好评轮播 3 秒自动切 + 悬停暂停 + 左右箭头。

【禁止】紫渐变、玻璃拟态、emoji 堆砌、Inter 当大标题。

以下是我的资料（方括号换成你的）：
【你的名字】
【你的一句话身份，如：AI 讲师 · 心理咨询师】
【你的一句话主张】
【三段介绍】
【两个服务/定价】
【3 个项目（标题+一句话+图）】
【你的城市】

④ 路线 B 提示词（英文设计源 · 你复制的那段）

原版设计库提示词（写给 React 工具）。粘到 WorkBuddy 也会生成，但产出是 React 工程，需要本地 npm 才能预览。

You are a senior frontend engineer. Build a personal portfolio website with React + Vite + Tailwind CSS.

Design language: Viktor Oddy / Vortex Studio style — dark, premium, lots of whitespace, scroll-driven narrative.
Colors: --ink #051A24, --ink2 #0D212C, --muted #273C46. Background pure white.
Fonts: 'PP Neue Montreal' for body, 'PP Mondwest' (fallback Fraunces/Georgia) for serif display.
Large radii (rounded-[40px]), soft multi-layer shadows.

Sections (top to bottom):
1. Hero — name (serif), role (mono), headline, 3 paragraphs, two rounded pill buttons.
2. Infinite marquee strip of images.
3. Testimonial quote + parallax image.
4. Two pricing cards (dark + light), rounded-40px.
5. Testimonial carousel (auto-play, arrows, hover pause).
6. Projects wall — 3 vertical projects with big images.
7. Partner CTA section with cursor-trail floating images on mousemove.
8. Footer + copyright.
9. Fixed bottom nav pill.

Animations: IntersectionObserver reveal, CSS marquee, parallax on scroll, 3s auto carousel.
No purple gradients, no glassmorphism, no emoji.

⑤ 别人操作的 SOP（手把手 7 步）

  1. 打开 WorkBuddy，新建一个对话。
  2. 复制「路线 A 提示词」整段（上面第③节那个灰框）。
  3. 粘贴到对话框，把【你的名字】【你的一句话身份】等所有方括号换成你自己的信息。
  4. 发送，等它生成 index.html（单文件，几秒到一分钟）。
  5. 双击本地 index.html 预览效果（手机也能看）。
  6. 换图：把自己真实照片 / 学员好评截图放进和 index.html 同一个文件夹，把代码里 img/xxx.png 改成你的图片文件名。
  7. 部署：用 WorkBuddy 的「发布 / 部署」功能，拿到一个谁都能点开的链接，发到群里。
关键提醒：路线 A 是"款式模板"——别人复制后填自己的信息，出来的是他自己的、但同款高级感的网站，不会变成小沅老师的站。图片一定要换成自己真实的，别留莫名其妙的图。
