② 复制哪段提示词

下面这段就是你给我的原版 VortxLab 设计提示词（零改动）。它原本是写给 AI 编程工具的设计源，我已还原成单文件 HTML（与前面几款一致，可直接部署、零代码）。别人粘到 WorkBuddy 就能出同款。
你是一个网页生成器。请基于下面【设计规格】和【我的个人信息】，生成一个单文件 HTML 个人主页：双击就能在浏览器打开、零依赖、不要 React/Vite 工程、所有 CSS/JS 内联、除了 Google Fonts 和背景视频外不引用任何外部文件。不要向我提问，直接生成完整 .html 文件。

【设计规格 · VortxLab 风格】
- 纯黑底色、全屏沉浸式。
- 字体用 Google Fonts 引入 Inter(300–900) + Noto Sans SC，写 preconnect，font-family: 'Inter','Noto Sans SC',sans-serif。
- 八边形切角按钮三档（CSS clip-path）：.btn-cut 实心 12px 切角 polygon(12px 0%,calc(100% - 12px) 0%,100% 12px,100% calc(100% - 12px),calc(100% - 12px) 100%,12px 100%,0% calc(100% - 12px),0% 12px)，白底黑字；.btn-cut-border 描边：白外框 + ::before(inset:1px 黑底 + 11px 切角) 做出白边黑底、文字白色；.btn-cut-sm 小号 8px 切角，用于社交圆钮。
- 入场动画：@keyframes fadeUp(opacity0→1,translateY24px→0) 与 fadeIn；.anim-stagger(opacity:0;animation:fadeUp .8s forwards) / .anim-fade(fadeIn 1s forwards)；各元素 inline animation-delay 错峰 0.1/0.2/0.4/0.5/0.7/0.85/1s。
- 背景：绝对定位铺满容器 object-fit:cover 的循环视频 <video autoplay loop muted playsinline>，src 用【我的个人信息】里的背景视频链接（空则用示例）。视频上盖 ::after 暗色渐变蒙版（顶/底加深）保证白字清晰。
- 布局：① 顶部 nav——左 Logo（四角星/漩涡 SVG + 文字「名字字标」）；右两个钮「导航按钮1」(.btn-cut-border 描边) +「导航按钮2」(.btn-cut 实心)。② 主体上半——左侧竖栏 left-col（仅 lg 显示）：标语 + 圆形头像（照片）+ 小标签「栏目名 / 序号」。③ 主体正中 h1 三行（行高紧、字距收、纯白、text-shadow）：领域标签 / 定位 / 姓名。④ 底部三栏（md 起三列）：左栏简介文字；中栏标签「栏目名」+ CTA「行动号召」(.btn-cut 实心 + ArrowRight 箭头 SVG)；右栏三个社交圆钮（微信/小红书/微博 inline SVG，链接填社交链接）。
- 响应式：nav 与左栏 < md/< lg 隐藏；底部 md 起三列；h1 字号断点递增(30→72px)。
- 兜底：@media (prefers-reduced-motion:reduce){.anim-stagger,.anim-fade{animation:none!important;opacity:1!important;}}；文字直接写 HTML 不依赖 JS；照片 <img> 加 onerror 兜底（失败隐藏图片、显示渐变底+一个字占位）。

【我的个人信息】（把内容换成我自己的；也可以直接把我的自我介绍/简历整段贴进来，你自行提取姓名、定位、简介等填到对应位置）

③ 别人操作的 SOP（手把手 7 步）

  1. 打开 WorkBuddy，新建一个对话。
  2. 复制上面「设计规格」整段（从"你是一个网页生成器"到"我的个人信息"结束）。
  3. 把【我的个人信息】部分换成你自己的真实资料（名字、定位、简介、社交链接）。
  4. 发送，等它生成 index.html（单文件，几秒到一分钟）。
  5. 双击本地 index.html 预览（手机也能看）。
  6. 换头像 / 背景视频：把自己的照片、视频放进和 index.html 同一个文件夹，把代码里 img/photo.jpg / 视频链接改成你的文件名。
  7. 部署：用 WorkBuddy 的「发布 / 部署」功能，拿到一个谁都能点开的链接，发到群里。
关键提醒：这段提示词是"款式模板"——别人复制后填自己的信息，出来的是他自己的、但同款酷感的网站，不会变成美瑶老师的站。背景视频若没有，可让 WorkBuddy 用你的证件照生成一段，或先留示例。
