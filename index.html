核心方法论

三步，从一句话到作品集

  • 第 1 步 · 描述效果：把想要的风格、配色、交互用自然语言告诉 AI（不用会写代码）。
  • 第 2 步 · AI 生成单文件 HTML：AI 输出一个 .html 文件，双击就能在浏览器打开，不依赖任何服务器。
  • 第 3 步 · 让 AI 汇总成汇报：把做好的几款一起发给 AI，让它打包成一个网页作品集并部署分享。
关键认知：你不是在「写网站」，是在「用指令指挥 AI 写网站」。
单款生成 · 指令模板

发给 AI 的「通用款式指令」

发给 AI 的指令（复制改 【】 即可）复制
请帮我做一个单文件 HTML 个人网站，风格是 【风格名，如 太空液态玻璃】。

要求：
1. 双击文件就能打开，不依赖本地服务器；
2. 主视觉：【描述，如 纯黑背景 + 蝴蝶慢动作视频】；
3. 配色：【如 黑 + 中国红】；
4. 交互：【如 鼠标跟随闪照片、滚动视差】；
5. 把 【xxx】 换成我真实的素材（图片 / 视频路径）。
要点：把【】里的占位词换成你的需求，其余原样发，AI 就能出同款。

关键 · 怎么汇总

把 7 款打包成一个作品集

汇总指令（复制改数量即可）复制
帮我做一份在线汇报，把我做好的个人网站风格汇总成
一个网页作品集。要求：
1. 每款用 iframe 内嵌可运行的实例；
2. 每款配一个 「📘 制作教程 / SOP」 按钮，
   点开是该款的提示词 + 复刻步骤；
3. 整体 深蓝黑底色 + 中国红点缀 + 玻璃拟态；
4. 顶部放 7 款的总览和对比；
5. 可直接部署、生成分享链接，所有人都能打开。
AI 会产出：一个总览页 + 每款的实例 + 每款的教程页，再帮你部署成链接。
→ 这就是你现在看到的这份汇报是怎么来的：一句话，让 AI 汇总。
复刻铁律

四条规矩，少走 90% 弯路

  • 换素材 ≠ 删效果：换图 / 换文案时，原排版、交互、动效一律保留，绝不顺手删。
  • 「我要一模一样」= 原样封装：只改引用路径，不擅自变体、不本地化改造。
  • 成品不留内部词：文件里绝不出现「给领导 / 给学员 / 演示用 / 占位」等暴露内部语境的词。
  • 封装旧站要把资产一起拷：视频 / 图片 / 字体等二进制必须一并复制，否则只剩静帧。
