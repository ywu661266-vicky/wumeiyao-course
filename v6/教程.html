② 复制哪段提示词

下面这段就是你给我的原版「太空液态玻璃」设计提示词（零改动）。它是写给 React 编程工具的，我已确认能跑通：window.Motion = window.Motion || window.FramerMotion（framer-motion 的 UMD 全局名是 Motion，写错会白屏）。别人粘到 WorkBuddy 就能出同款。
你是一个网页生成器。请基于下面【设计规格】和【我的个人信息】，生成一个单文件 HTML 个人主页：双击就能在浏览器打开、零依赖、不要 React/Vite 工程、所有 CSS/JS 内联、除了 Google Fonts 和背景视频外不引用任何外部文件。不要向我提问，直接生成完整 .html 文件。

【设计规格 · 太空液态玻璃风】
- 字体 Google Fonts 引 Instrument Serif(ital@1) + Barlow(300;400;500;600) + Noto Serif SC 中文兜底。
- CDN：tailwindcss / react@18.3.1 / react-dom@18.3.1 / @babel/standalone@7.29.0 / framer-motion@11.11.17（不要加 integrity 哈希）。
- framer-motion 加载后必写：window.Motion = window.Motion || window.FramerMotion（UMD 全局名为 Motion）。
- Tailwind 配置 font-heading→Instrument Serif、font-body→Barlow，默认圆角 pill（DEFAULT:9999px）。
- 液态玻璃 CSS 原样写：.liquid-glass（rgba(255,255,255,0.01)+blur(4px)+1.4px 渐变描边 mask-composite xor）；.liquid-glass-strong（blur(50px)）。
- FadingVideo 组件：rAF 逐帧控透明度、FADE_MS=500、距结束 0.55s 开始淡出、ended 后 100ms 重置重播、关掉 loop、视频上绝不用 CSS transition。
- BlurText：IntersectionObserver 触发（10% 可见），按空格分词，每词 motion.span；initial {filter:'blur(10px)',opacity:0,y:50} 三段关键帧到 {blur(5)→blur(0),opacity .5→1,y -5→0}；duration .7、times [0,.5,1]、easeOut、逐词 delay=i*0.1s、父级 flex 换行居中。
- 各区块 Framer Motion 入场 delays 依次：徽章 .4 / 副标 .8 / 按钮 1.1 / 数据卡 1.3 / 伙伴 1.4。
- 全站白字、不要绿色、不要渐变背景；视频上不加暗色蒙版；对比靠玻璃质感。
- 双屏结构：① Hero（顶部玻璃胶囊导航 + 大标题逐词入场 + 副标 + 两个主/次按钮 + 两张数据卡 + 合作伙伴行）；② Capabilities（视频全屏铺满 + 左上 kicker + 大标题两行 + 三张能力卡，每张含图标 + 4 个标签 + 标题 + 描述）。

【我的个人信息】（自动拆分到大标题 / 副标题 / 徽章 / 5 导航 / 主次按钮 / 两张数据卡 / 5 合作伙伴 / 三张能力卡）：
- 名字：美瑶老师
- 身份：AI 讲师 × 心理咨询师 × 高级人工智能训练师
- 主张：用 AI 与心理学，陪女性长出力量

③ 别人操作的 SOP（手把手 7 步）

  1. 打开 WorkBuddy，新建一个对话。
  2. 复制上面整段提示词（从"你是一个网页生成器"到最后）。
  3. 把【我的个人信息】换成你自己的真实资料（名字、定位、主张、三张能力卡主题）。
  4. 发送，等它生成 index.html（React + Babel 单文件，几十秒到一两分钟）。
  5. 双击本地 index.html 预览——首次打开需联网加载 React/Framer Motion（CDN）。
  6. 换背景视频：把你的视频链接或本地视频放进同文件夹，改代码里的视频 src。
  7. 部署：用 WorkBuddy 的「发布 / 部署」功能，拿到一个谁都能点开的链接，发到群里。
关键提醒：这两段视频用的是远程链接，部署后别人有网就能看；若失效，页面会先显示深空黑底+星点兜底（不会白屏）。这段提示词是"款式模板"——别人填自己信息出的是他自己同款站。
